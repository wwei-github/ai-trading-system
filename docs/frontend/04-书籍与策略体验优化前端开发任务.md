# 04 书籍与策略体验优化 — 前端开发任务

## 1. 背景与目标

### 1.1 当前问题

| 问题 | 当前表现 | 目标 |
|------|----------|------|
| 解析进度 | 上传后触发解析，但页面无进度条，用户不知道解析状态 | 显示实时进度条、阶段描述、章节/知识块统计 |
| 解析结果 | 解析完成后页面无变化，用户无法感知解析结果 | 解析完成后自动刷新，显示章节数、知识块数 |
| 书籍内容 | 阅读器使用 `SYNTHETIC_CHAPTERS` + `SAMPLE_PARAGRAPHS` 模拟数据 | 阅读器调用真实 API 展示章节内容 |
| 书籍生成策略 | 页面无"AI 分析"入口，用户不知道可以从书籍生成策略 | 书籍详情增加"AI 分析"按钮，展示分析报告和交易系统 |
| 策略页面操作 | 策略编辑使用原始 JSON 输入框，不好用 | 结构化编辑表单，规则可视化编辑 |

### 1.2 相关文件清单

## 6. 页面交互流程

### 6.1 书籍学习全流程

```
用户上传书籍文件
    │
    ▼
书籍上传成功 → 自动选中 → 触发解析
    │
    ▼
解析中（轮询进度）
    ├── 显示进度条 + 阶段描述
    ├── 显示已解析章节数 / 知识块数
    └── 失败时显示错误 + 重试按钮
    │
    ▼
解析完成（自动刷新）
    ├── 章节列表可查看
    ├── 阅读器展示真实内容
    ├── AI 问答可用
    ├── 知识提取可用
    └── AI 分析生成策略按钮可用
    │
    ▼
点击"AI 分析生成策略"
    ├── 弹窗显示分析报告（Markdown）
    ├── 弹窗显示生成的交易系统
    └── 策略自动保存到策略库
```

### 6.2 策略管理全流程

```
策略库 Tab
    ├── 列表展示所有策略
```
