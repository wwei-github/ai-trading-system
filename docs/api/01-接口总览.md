## 2. 认证与鉴权

当前阶段（v1）为无登录快速启动模式，使用默认用户进行数据隔离。

- 方式：请求头 `X-API-Key`（预留）或 Cookie 中的 `access_token`
- 在本地开发时，即使不传递任何鉴权信息，依赖注入会自动使用 `DEFAULT_USER_ID` 对应的用户
- 如需切换为 JWT 模式，可修改 `app/api/deps.py` 中的 `get_current_user` 实现

## 3. 通用响应格式

除 SSE 流式接口外，所有成功响应统一使用 `ApiResponse<T>` 结构包装：

```json
{
  "code": 0,
  "message": "ok",
  "data": { "...": "业务数据" },
  "timestamp": 1720000000000
}
```

### 错误响应

```json
{
  "code": 40001,
  "message": "资源不存在",
  "detail": { "book_id": "xxx" },
  "timestamp": 1720000000000
}
```

常见错误码：

| code | 含义 | HTTP 状态 |
|---|---|---|
| 0 | 成功 | 2xx |
| 40001 | 通用 BadRequest（参数/业务校验失败） | 400 |
| 40101 | 未认证 | 401 |
| 40301 | 无权限 | 403 |
| 40401 | 资源不存在 | 404 |
| 40901 | 资源冲突（如重名） | 409 |
| 50001 | 内部服务器错误 | 500 |

## 4. 分页参数

所有列表型接口（如 `/trades`、`/strategies` 等）使用统一的分页参数：

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `page` | integer | 1 | 页号（从 1 开始） |
| `page_size` | integer | 20 | 每页数量（最大 200） |

对应响应中 `data` 为列表分页结果（列表接口），或在有总计需求时可通过 `X-Total-Count` 响应头 / 内嵌 metadata 获取。

## 5. 日期与时间

- 所有时间字段使用 ISO 8601 格式，字符串形式，统一 UTC 时区（带 `Z` 后缀）
- 日期区间参数（如 `start_date` / `end_date`）接受 `YYYY-MM-DD`

## 6. 文件上传与下载

- 上传：`multipart/form-data`，`Content-Type: multipart/form-data`
- 下载：响应头 `Content-Type: application/octet-stream`，`Content-Disposition: attachment; filename="..."`

当前支持的上传接口：

- `POST /api/v1/books/upload` — 上传书籍文件（pdf/epub/txt，最大 50MB）
- `POST /api/v1/trades/import` — 导入交易记录（csv）

## 7. SSE 流式接口

- `POST /api/v1/ai/conversations/{conversation_id}/stream`
- 响应 `Content-Type: text/event-stream`
- 事件以 `data: {...}\n\n` 分隔，末尾以 `data: [DONE]\n\n` 标记结束
- 务必在请求端禁用缓冲（`X-Accel-Buffering: no`）
