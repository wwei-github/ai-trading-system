## POST `/api/v1/ai/conversations`

**创建会话**

创建 AI 会话。

### 请求参数

_(无)_

### 请求体

- `Content-Type: application/json`
  - Schema: [AIConversationCreate](./10-schemas.md#AIConversationCreate)
  - 字段明细：

    | 字段 | 类型 | 必填 | 说明 |
    |---|---|---|---|
    | mode | string | 否 | 会话模式：trade_analysis/strategy/book_qa/general/report |
    | title | any | 否 | Title |
    | context | any | 否 | Context |


### 响应

| HTTP | 说明 | Schema |
|---|---|---|
| 201 | Successful Response | any |
| 422 | Validation Error | [HTTPValidationError](./10-schemas.md#HTTPValidationError) |
