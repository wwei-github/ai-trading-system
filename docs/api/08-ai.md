## 1. 会话管理

### 1.1 获取会话列表

```
GET /ai/conversations
```

返回当前用户的全部 AI 会话，按创建时间倒序。

**返回结果：**

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": "uuid",
      "user_id": "uuid",
      "mode": "trade_analysis",
      "title": "会话-20260814100000",
      "context": {"account_id": "uuid"},
      "created_at": "2026-08-14T10:00:00Z",
      "updated_at": "2026-08-14T10:05:00Z"
    }
  ]
}
```

### 1.2 创建会话

```
POST /ai/conversations
```

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mode | string | 否 | 会话模式：trade_analysis/strategy/book_qa/risk_diagnosis/general（默认 general） |
| title | string | 否 | 会话标题（留空自动生成 `会话-时间戳`） |
| context | object | 否 | 上下文信息（如 `{"book_id": "uuid"}`、`{"account_id": "uuid"}`） |

**返回结果：** 同 1.1 单条会话对象，HTTP 201。

### 1.3 获取会话详情

```
GET /ai/conversations/{conversation_id}
```

**错误响应：** 会话不存在返回 404。

### 1.4 重命名会话

```
PATCH /ai/conversations/{conversation_id}
```

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 新标题（最长 200 字符） |

**返回结果：** 更新后的会话对象。

### 1.5 删除会话

```
DELETE /ai/conversations/{conversation_id}
```

删除会话及其关联的全部消息。

**返回结果：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {"deleted": true}
}
```

## 2. 消息交互

### 2.1 获取消息列表

```
GET /ai/conversations/{conversation_id}/messages
```

返回会话内全部消息，按创建时间升序（最早在前）。

**返回结果：**

```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "id": "uuid",
      "conversation_id": "uuid",
      "role": "user",
      "content": "分析一下我最近的交易表现",
      "tokens_used": null,
      "feedback": "none",
      "created_at": "2026-08-14T10:00:00Z"
    },
    {
      "id": "uuid",
      "conversation_id": "uuid",
      "role": "assistant",
      "content": "根据您的交易数据...\n\n---\n⚠️ **免责声明**：以上内容由 AI 生成...",
      "tokens_used": 580,
      "feedback": "like",
      "created_at": "2026-08-14T10:00:05Z"
    }
  ]
}
```

### 2.2 发送消息（同步）

```
POST /ai/conversations/{conversation_id}/messages
```

发送用户消息并同步等待 AI 回复。AI 回复末尾自动追加免责声明。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 是 | 消息内容 |
| context | object | 否 | 附加上下文（覆盖会话级 context） |

**返回结果：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "user_message": { /* 同 2.1 消息对象 */ },
    "assistant_message": { /* 同 2.1 消息对象 */ }
  }
}
```

### 2.3 流式对话（SSE）

```
POST /ai/conversations/{conversation_id}/stream
```

以 Server-Sent Events 流式返回 AI 回复的增量内容。

**请求体：** 同 2.2。

**响应格式：** `text/event-stream`

```
data: {"content": "根据您的"}

data: {"content": "交易数据..."}

data: {"content": "\n\n---\n⚠️ **免责声明**..."}

data: [DONE]
```

**错误处理：** 出错时输出 `data: {"error": "错误信息"}` 后以 `[DONE]` 结束。

## 3. 消息反馈

### 3.1 消息点赞/点踩

```
POST /ai/messages/{message_id}/feedback
```

对 AI 消息进行反馈，用于模型质量追踪。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| feedback | string | 是 | 反馈类型：`like` / `dislike` / `none` |

**返回结果：** 更新后的消息对象（同 2.1 单条消息）。

**错误响应：**
- 消息不存在：404
- 无效反馈类型：400

## 4. 交易信号

### 4.1 生成交易信号

```
POST /ai/signals/generate
```

调用 LLM 生成交易信号并持久化到 `signals` 表，初始状态为 `pending`。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| symbol | string | 是 | 交易对（如 `BTC/USDT`） |
| strategy_id | UUID | 否 | 关联策略 ID |
| context | object | 否 | 附加上下文（指标数据、市场环境等） |

**返回结果（HTTP 201）：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "uuid",
    "symbol": "BTC/USDT",
    "side": "buy",
    "strength": 0.75,
    "reason": "RSI 超卖反弹，MACD 金叉形成，成交量放大",
    "source": "ai",
    "status": "pending",
    "strategy_id": "uuid",
    "context": {"rsi": 28, "macd": "golden_cross"},
    "created_at": "2026-08-14T10:00:00Z"
  }
}
```

| 字段 | 取值范围 | 说明 |
|------|----------|------|
| side | `buy` / `sell` / `hold` | 交易方向 |
| strength | 0.0 ~ 1.0 | 信号强度 |
| source | `ai` / `rule` | 信号来源 |
| status | `pending` / `adopted` / `ignored` / `executed` | 信号状态 |

### 4.2 获取信号列表

```
GET /ai/signals
```

获取当前用户的交易信号列表，按创建时间倒序。

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| symbol | string | 否 | 按交易对过滤 |
| status | string | 否 | 按状态过滤：pending/adopted/ignored/executed |
| source | string | 否 | 按来源过滤：ai/rule |
| limit | int | 否 | 返回条数（默认 50，范围 1~200） |

**返回结果：** 同 4.1 `data` 字段的数组形式。

### 4.3 标记信号状态

```
POST /ai/signals/{signal_id}/mark
```

将信号标记为已采纳 / 已忽略 / 已执行。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | string | 是 | 目标状态：`adopted` / `ignored` / `executed`（也可回退为 `pending`） |

**返回结果：** 更新后的信号对象。

**错误响应：**
- 信号不存在或不属于当前用户：404
- 无效状态：400

## 5. 分析报告

### 5.1 生成分析报告

```
POST /ai/reports/generate
```

调用 LLM 生成结构化分析报告（5 章 Markdown），并持久化到 `reports` 表。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| report_type | string | 否 | 报告类型：`trade`（默认）/ `strategy` / `portfolio` |
| period | string | 否 | 报告周期：`daily` / `weekly` / `monthly` / `custom`（默认 custom） |
| start_date | string | 否 | 起始时间（ISO 8601） |
| end_date | string | 否 | 结束时间（ISO 8601） |
| context | object | 否 | 附加上下文数据 |

**返回结果（HTTP 201）：**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": "uuid",
    "report_type": "trade",
    "period": "weekly",
    "title": "交易表现分析报告",
    "content": "# 交易表现分析报告\n\n## 1. 概述\n...\n## 5. 改进建议\n...\n\n---\n⚠️ **免责声明**...",
    "summary": "本周共完成 12 笔交易，胜率 58%，累计收益 +3.2%...",
    "period_start": "2026-08-07T00:00:00Z",
    "period_end": "2026-08-14T00:00:00Z",
    "created_at": "2026-08-14T10:00:00Z"
  }
}
```

**报告 5 章结构：**

| 章节 | 内容 |
|------|------|
| 1. 概述 | 报告概要、关键结论 |
| 2. 关键指标分析 | 胜率、盈亏比、夏普比率等 |
| 3. 趋势分析 | 收益曲线、品种分布 |
| 4. 风险评估 | 最大回撤、波动率 |
| 5. 改进建议 | 可执行的优化方向 |

### 5.2 获取报告列表

```
GET /ai/reports
```

获取当前用户的分析报告列表，按创建时间倒序。

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| report_type | string | 否 | 按类型过滤：trade/strategy/portfolio |
| period | string | 否 | 按周期过滤：daily/weekly/monthly/custom |
| limit | int | 否 | 返回条数（默认 20，范围 1~100） |

**返回结果：** 同 5.1 `data` 字段的数组形式。

### 5.3 获取报告详情

```
GET /ai/reports/{report_id}
```

获取指定报告的完整 Markdown 内容。

**错误响应：** 报告不存在或不属于当前用户：404。

## 6. 会话模式说明

不同会话模式使用不同的系统提示词，影响 AI 的回答风格和侧重点：

| 模式 | 系统提示词定位 | 典型场景 |
|------|----------------|----------|
| `trade_analysis` | 交易分析师，基于数据分析表现 | 复盘交易、识别问题 |
| `strategy` | 量化策略专家，设计优化策略 | 策略设计、参数调优 |
| `book_qa` | 知识助手，基于书籍 RAG 回答 | 阅读答疑、知识点查询 |
| `risk_diagnosis` | 风险管理专家，诊断风险敞口 | 持仓风险评估 |
| `general` | 通用助手 | 自由问答 |

### book_qa 模式的 RAG 检索

当会话模式为 `book_qa` 且 `context.book_id` 存在时，每条用户消息会触发：
1. 调用 `BookService.retrieve_relevant_chunks` 进行向量检索（top 5）
2. 将检索到的知识片段作为参考信息注入 LLM 上下文
3. AI 回复中会标注引用来源（片段序号 + 章节序号 + 相似度）

### 免责声明

所有 AI 回复（同步、流式、报告内容）末尾自动追加：

```
---
⚠️ **免责声明**：以上内容由 AI 生成，仅供参考，不构成投资建议。交易有风险，投资需谨慎。
```

## 7. 数据模型

### AIConversation（AI 会话）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 所属用户 |
| mode | string(50) | 会话模式 |
| title | string(200) | 会话标题 |
| context | JSONB | 上下文信息 |

### AIMessage（AI 消息）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| conversation_id | UUID | 所属会话 |
| role | string(20) | 角色：user / assistant / system |
| content | text | 消息内容 |
| tokens_used | int | 消耗 token 数 |
| feedback | string(10) | 用户反馈：none / like / dislike |

### Signal（交易信号）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 所属用户 |
| strategy_id | UUID | 关联策略（可空） |
| symbol | string(30) | 交易对 |
| side | string(10) | 方向：buy / sell / hold |
| strength | float | 信号强度 (0.0~1.0) |
| reason | text | 信号原因 |
| source | string(10) | 来源：ai / rule |
| status | string(20) | 状态：pending / adopted / ignored / executed |
| context | JSONB | 附加上下文 |

### Report（分析报告）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 所属用户 |
| report_type | string(20) | 类型：trade / strategy / portfolio |
| period | string(20) | 周期：daily / weekly / monthly / custom |
| title | string(200) | 报告标题 |
| content | text | 报告内容（Markdown，5 章结构） |
| summary | text | AI 摘要 |
| period_start | datetime | 报告起始时间 |
| period_end | datetime | 报告结束时间 |
| context | JSONB | 附加上下文 |
