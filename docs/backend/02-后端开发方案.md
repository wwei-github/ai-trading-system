## 1. 开发总览与交付节奏

### 1.1 与 PRD §11 里程碑对齐

| 里程碑 | PRD 周期 | 本方案阶段 | 阶段交付（DoD） |
|--------|----------|-----------|------------------|
| M1 基础框架 | 第 1-3 周 | Stage 0 + Stage 1 | 脚手架/模式切换/建表已完成；补齐 JWT 鉴权、RBAC 角色系统（之前跳过的登录流程） |
| M2 账号与交易 | 第 4-7 周 | Stage 2 + Stage 3 | 6 大交易所 API 连接、余额同步、交易自动同步 + 去重、手动交易 CRUD、CSV/XLSX 导入导出 |
| M3 统计与币种 | 第 8-10 周 | Stage 4 + Stage 5 | 12 指标计算引擎、9 报表、Top100 币种行情聚合、K 线/14 类技术指标后端计算接口 |
| V1.1 策略版 | M4-M5 | Stage 6 | 回测引擎（numpy 向量化）、策略参数 DSL 解析与校验、模拟交易引擎、Celery 调度 |
| V1.2 学习版 | M5-M6 | Stage 7 | 书籍解析（unstructured + PyMuPDF）、分块、Embedding、pgvector 向量库、知识提取 Prompt |
| V1.3 AI 增强 | M7-M8 | Stage 8 | 5 模式 AI 对话、RAG 检索、信号生成、定时报告（日报/周报/月报） |
| V2.0 团队版 | M9-M12 | Stage 9 | 多租户隔离、子账号、分仓、团队绩效（后续迭代） |

### 1.2 DoD（Definition of Done）

每个阶段完成时：
- 所有新增 API 在 `/docs`（Swagger UI）可测试
- 单元测试覆盖率 ≥ 70%（pytest-cov）
- 三种模式（local/docker/online）接口行为一致（除依赖 PG 向量外）
- Alembic 迁移脚本存在并在 Docker 启动时 entrypoint 自动执行（保留 create_all 兜底）
- Celery 任务均有 `max_retries`、`retry_backoff`、超时、失败回调记录
- 对应开发文档同步更新

## 5. 关键技术点解决方案

| 技术点 | 方案 | 原因 |
|--------|------|------|
| **JWT + Refresh** | python-jose（cryptography backend） + passlib[bcrypt] + Redis 黑名单；Refresh Token 存储 DB | python-jose 类型友好；Redis 黑名单确保"登出即刻失效"（避免等 30min） |
| **权限 RBAC** | FastAPI Depends 装饰器模式 `require_roles("Trader")`；路由标签自动审计 | 无侵入；可组合 |
| **AES-256-GCM 加密** | cryptography `AESGCM`；nonce 每次随机；密文 = `base64(nonce + ciphertext + tag)`；密钥长度 32 字节；密钥与 DB 分离 | GCM 模式带认证（防止篡改）；行业标准 |
| **Celery 任务** | broker=Redis 6；result backend=PostgreSQL（或 Redis）；serializer=msgpack；autoretry；flower 监控（可加）；并发数=CPU*2 | msgpack 比 JSON 小 40%；PostgreSQL 结果持久化 |
| **邮件** | fastapi-mail；默认 SMTP；可选发送失败入死信队列；测试模式文件输出 | 成熟 |
| **策略回测性能** | NumPy / Pandas 向量化；Cython 加速瓶颈函数（可选）；1 年 1h 单测 ≤ 10s；可多进程批量参数搜索（V1.1 网格） | 比纯 Python 循环快 10~100x |
| **模拟引擎实时行情** | 后端统一 WebSocket 连接交易所；多策略订阅用"发布-订阅"模式（asyncio.Queue 一对多分发） | 避免每个策略独立建连接 |
| **向量库** | **pgvector**（依赖 Postgres，新增无额外服务；Docker 镜像切换到 `pgvector/pgvector:pg15`）；`tbl_knowledge_chunks` 加 `HNSW` 索引；向量维度与 Embedding 模型一致（1536 或 1024） | 避免引入 Milvus（运维成本高）；PRD §12 TBD-2 默认选 pgvector |
| **RAG 分块** | unstructured.io（按章节边界）→ 回退 LangChain RecursiveCharacterTextSplitter；重叠 10% | 语义边界分块质量高 |
| **AI 流式响应** | ServerSentEvent：FastAPI StreamingResponse + `yield`；Token 实时增量；前端 EventSource/fetch stream 兼容 | 比 WebSocket 更轻；天然 HTTP/2 多路复用 |
| **大文件流式导入导出** | FastAPI StreamingResponse；Excel 用 openpyxl write-only mode；CSV 内置 csv.writer 逐行；导入分块解析 1000 行/事务 | 避免 OOM |
| **K线分区存储** | PostgreSQL 分区表：按 symbol, timeframe LIST 分区；按 open_time RANGE 子分区；索引 (symbol, tf, open_time) UNIQUE | 大表查询性能提升 10x+ |
| **审计日志 Diff** | `deepdiff.DeepDiff`（before/after dict → JSON 存详情页；可选压缩） | Diff 结果前端可直接可视化 |
| **币种相关性矩阵** | `pandas.DataFrame.pct_change().corr()`；N×N 返回为 JSON 下三角（对称），前端还原 | numpy 计算快速 |

### 命名约定
- **模型类**：`PascalCase`（单数）`User / ExchangeAccount / TradeTag`
- **Schema 类**：请求 `{Entity}Create / {Entity}Update / {Entity}ListParams`；响应 `{Entity}Response / Paginated{Entity}Response`
- **Service 类**：`{Domain}Service`（单例无状态，推荐用 classmethod 或模块级函数）
- **Celery 任务**：`{domain}_{action}_{scope}`，如 `account_sync_balance`
- **工具函数**：`camelCase` 或 `snake_case`（Python 用 snake_case）

## 13. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| JWT + 鉴权实现失误导致越权 | 中 | 极高 | 1) Depends 单测覆盖所有角色组合 2) E2E 验证 Viewer 无法 DELETE 3) 审计日志定期抽样检查 |
| 提币功能误开导致资金损失 | 低 | 极高 | V1 代码中提币接口固定抛异常；配置开关无法绕过；代码 review + 单测双重锁定 |
| 实盘风控漏判 | 中 | 极高 | 8 阈值每类单独 UT + 集成测试 + 压测；灰度阶段仅允许"人工确认下单" |
| 交易所 API Key 泄漏（员工/日志/DB） | 低 | 极高 | AES-GCM 密文；密钥分离；日志审计中间件；DB 备份加密；员工权限最小化；变更审批 |
| AI 幻觉导致错误建议（合规） | 高 | 中 | 免责声明强制尾注；策略/风险/市场三类 AI 结果标注"非投资建议"；信号仅推送不下单 |
| Celery 任务堆积/死信 | 中 | 中 | flower 监控队列；超时 + 最大重试 + 死信队列；失败回写入 audit 失败表报警 |
| RAG 向量检索质量差 | 中 | 中 | 语义分块 + 重叠 + Reranker；Embedding 模型 A/B 测试；人工抽检 20 题 Top-N 召回率 |
| 回测结果与实盘偏差大（过拟合/滑点忽略） | 高 | 中 | 强制配置滑点 + 手续费；回测报告高亮"滑点敏感性"；策略启动前要求在模拟运行 ≥ 2 周 |
| pgvector 向量查询性能（百万级） | 中 | 中 | HNSW 索引（m=16, ef_construction=64）；查询前预热；按用户分桶并行；必要时 Milvus（TBD-2） |
| K 线 WS 资源浪费 / 连接数过多 | 中 | 中 | 后端统一 WS 到交易所；多策略共享同一连接；订阅引用计数；空闲 5 分钟退订 |
| 邮件 / 短信服务商不可用 | 中 | 低 | 重试队列 + 多渠道降级（邮件失败降级站内信） |
